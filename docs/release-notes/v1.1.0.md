**Run multiple Claude accounts at the same time** (for example Work and Personal) in the Claude desktop app and Claude Code, now on **Windows and macOS**.

## What's new in 1.1.0

- 🍎 **macOS version (new).** A menu bar app for macOS 12+ on Apple Silicon and Intel. It has profiles for the Claude desktop app (`--user-data-dir`) and Claude Code (`CLAUDE_CONFIG_DIR` in Terminal), the same safety checks (symlinks resolved, existing `~/.claude` and Claude app data never touched), a first sign-in check, and live "running" status. It doesn't need .NET installed.
- 🎨 **New Windows tray panel.** A Windows 11-style flyout that follows light/dark mode and your accent color, with profile cards that show which accounts are running and how much memory they use, themed menus, and auto-hide with a pin button.
- ✏️ **Redesigned profile editor.** A live preview, Windows 11-style text boxes, color swatches, an icon grid, and errors shown inside the window.
- 🖼️ **Profile icons.** The Claude icon with a color badge by default, built-in presets, or your own image.
- 🔁 **Automated builds.** Every release is built and self-tested on Windows and macOS by GitHub Actions.

|---|---|
| **Windows 10/11** (recommended) | `ClaudeManager-Setup-1.1.0.exe`: per-user installer, no admin rights |
| Windows, portable | `ClaudeManager-1.1.0-portable.zip` |
| **macOS, Apple Silicon** (M1–M4) | `ClaudeManager-1.1.0-macos-arm64.dmg` (or `.zip`) |
| **macOS, Intel** | `ClaudeManager-1.1.0-macos-x64.dmg` (or `.zip`) |
| Checksums | `SHA256SUMS.txt` |

**Windows:** needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) (Windows offers it). The installer isn't code-signed yet: if SmartScreen appears, click **More info → Run anyway**.

**macOS:** open the DMG and drag Claude Manager to Applications. The app isn't notarized yet, so the first time, **right-click → Open → Open**, or run `xattr -dr com.apple.quarantine "/Applications/Claude Manager.app"`. It lives in the menu bar.

## Known limitations

- **macOS:** sign-in links can't be routed yet, so quit other Claude windows during a profile's *first* sign-in (the app reminds you). The settings backup and custom image icons are Windows-only for now. The app is ad-hoc signed, not notarized.
- Desktop isolation relies on Claude's `--user-data-dir` flag, which Anthropic doesn't document. Claude Manager checks that each new profile really uses its own folder.
