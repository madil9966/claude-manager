First public release of **Claude Manager**, a small Windows tray app that runs several Claude accounts side by side (for example Work and Personal) for both the **Claude desktop app** and **Claude Code**, without logging out and in.

## Download

| File | What it is |
|---|---|
| **`ClaudeManager-Setup-1.0.0.exe`** | Installer (recommended). Per-user, **no admin rights**, appears in Apps & Features. |
| `ClaudeManager-1.0.0-portable.zip` | Portable: unzip anywhere and run `ClaudeManager.exe`. |
| `SHA256SUMS.txt` | Checksums to verify the downloads. |

**Requirements:** Windows 10 or 11 (x64), the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) (Windows offers to install it if it's missing), and the Claude desktop app and/or Claude Code.

> ⚠️ The installer isn't code-signed yet, so Windows SmartScreen may say *"Windows protected your PC"*. Click **More info → Run anyway**. You can check the file against `SHA256SUMS.txt` first: `Get-FileHash .\ClaudeManager-Setup-1.0.0.exe`.

## Features

- **Profiles for desktop and CLI.** Each profile opens its own Claude desktop window (`--user-data-dir`) and its own Claude Code terminal (`CLAUDE_CONFIG_DIR`, for that tab only).
- **Your current setup stays untouched.** `~\.claude`, `~\.claude.json` and `%APPDATA%\Claude` are never written, moved or deleted. One safety gate checks every write, including junctions, symlinks, 8.3 short names and `subst` drives.
- **Google sign-in goes to the right profile.** `claude://` sign-in links are routed to the profile being set up, instead of always opening the default account.
- **Modern tray panel.** A Windows 11-style flyout that follows light/dark mode and your accent color. Each profile is a card showing whether it's running and how much memory it uses.
- **Profile icons.** The Claude icon with a color badge by default, built-in presets, or your own image.
- **Safe backup.** A zip of your settings with secrets removed (API keys, tokens, MCP `env`/`headers`). Login tokens are never copied.
- **Safeguards.** Old Claude Code versions that would modify `~\.claude.json` are blocked. The current Claude version is always launched. Damaged settings are restored from backup automatically.
- **Clean uninstall.** Removes shortcuts, the startup entry and link routing, and hands `claude://` back to Claude. Your accounts, profile folders and chats are never deleted.
- **Privacy.** No telemetry. Logins, tokens and chats are never read or sent.

## Quick start

1. Install, then open Claude Manager from the Start menu or the tray.
2. Choose profile names (for example Work and Personal).
3. Click **Desktop** on a new profile and sign in with that account (Google sign-in works).
4. Click **Terminal** to use Claude Code with that account, then type `/login` once.

Silent install: `ClaudeManager-Setup-1.0.0.exe /S [--dir="C:\path"] [--no-desktop] [--no-startup] [--launch]` · Silent uninstall: `ClaudeManager.exe --uninstall --quiet`

## Known limitations

- The desktop app's isolation relies on Claude's `--user-data-dir` flag, which Anthropic doesn't document and could change. Claude Manager checks that each new profile really uses its own folder and warns you if it doesn't.
- The installer isn't code-signed yet (see the SmartScreen note above).
- Only tested with the classic Claude desktop install. The Microsoft Store version should work but hasn't been tested yet.
